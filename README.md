# cassava-starch-curcumin-aloe-hydrogel
Pengembangan hidrogel berbasis pati singkong dengan PEG 400 untuk penghantaran nanoemulsi kurkumin–Aloe vera dengan pelepasan bergantung pH sebagai kandidat wound dressing luka bakar derajat II. Repositori ini memuat dokumentasi, formulasi, prosedur, data eksperimen, analisis, dan desain penelitian.
